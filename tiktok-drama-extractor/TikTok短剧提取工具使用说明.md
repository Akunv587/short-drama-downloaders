# TikTok 短剧剧集链接一键提取工具

## 🎯 解决什么问题？

你的工作流程中最繁琐的环节：在TikTok上手动逐集复制60个视频URL。

**优化前：** 每部短剧60集 → 逐集点击右侧列表 → 复制地址栏URL → 粘贴到哼哼猫（每15个一批，要4轮）
**优化后：** 在TikTok短剧页面点击书签 → 自动滚动提取全部链接 → 一键复制 → 粘贴到哼哼猫（一次搞定）

效率提升：**360次手动复制 → 6次一键提取**

---

## 📦 安装方法（3步）

### 第1步：复制Bookmarklet代码

打开下方文件 `tiktok-extract-bookmarklet-minified.js`，复制其中 `javascript:` 开头的**完整一行代码**。

### 第2步：创建浏览器书签

1. 在Chrome/Edge浏览器中，按 `Ctrl+D` 新建一个书签
2. **名称**填写：`提取TikTok剧集`
3. **URL/地址栏**中：删除默认地址，粘贴刚才复制的 `javascript:` 代码
4. 点击保存

> 💡 如果你的书签栏没显示，按 `Ctrl+Shift+B` 开启书签栏

### 第3步：验证安装

随便打开一个TikTok视频页面（如 `https://www.tiktok.com/@happydrama_a/video/...`），点击刚创建的书签。如果右上角弹出蓝色面板，说明安装成功。

### 操作流程（对比原流程）

| 原流程 | 新流程 |
|--------|--------|
| 1. 剧查查查热播榜 → 筛选 | 1. 剧查查查热播榜 → 筛选（不变） |
| 2. TikTok搜短剧名 | 2. TikTok搜短剧名（不变） |
| 3. 点开第一集 | 3. 点开第一集（不变） |
| 4. **逐集手动复制URL×60次** | 4. **点击"提取TikTok剧集"书签** |
| 5. 分4批粘贴到哼哼猫（每批15个） | 5. **一键复制全部链接，粘贴到哼哼猫（1次搞定）** |
| 6. 哼哼猫下载视频 | 6. 哼哼猫下载视频（不变） |
| 7. 上传公司系统 → 解析 | 7. 上传公司系统 → 解析（不变） |
| 8. 复制剧本 → docx → 飞书 | 8. 复制剧本 → docx → 飞书（不变） |

### 详细步骤

1. **在TikTok搜索短剧名称**（如搜索"Strangers Upon Meeting"）
2. **点击搜索结果中的第一集**，进入视频播放页面
3. **点击书签栏的"提取TikTok剧集"**
4. 右上角弹出蓝色面板，自动开始滚动加载
5. 等待滚动完成（面板显示"✅ 完成！共找到 XX 个剧集链接"）
6. **点击"📋 复制纯净链接(去参数)"按钮**（推荐，去掉了URL中的查询参数，哼哼猫更容易识别）
7. **打开哼哼猫**，在多链接批量提取中粘贴所有链接
8. 一次性批量下载整部短剧，完成！

## 🔧 两个复制按钮的区别

| 按钮 | 说明 | 推荐场景 |
|------|------|----------|
| 📋 复制纯净链接(去参数) | 只保留 `/@用户名/video/视频ID` 部分 | ⭐ **推荐用于哼哼猫**，链接更干净，解析更快 |
| 📋 一键复制全部链接 | 保留完整URL含查询参数 | 需要保留搜索上下文时使用 |

## ⚠️ 重要注意事项

### 1. 必须在TikTok视频播放页面上运行
脚本通过URL识别创作者用户名。如果你的URL不是 `https://www.tiktok.com/@某某/video/...` 格式，脚本会提示错误。

### 2. 可能提取到其他短剧的链接
TikTok右侧剧集列表可能包含该创作者的其他短剧。如果提取到的链接数量远超一部短剧的集数（比如超过100个），说明包含了多部短剧。
- **解决方法：** 在哼哼猫粘贴链接后，可以先全部下载，然后在公司系统上传时只选择目标短剧的视频

### 3. TikTok页面结构可能变化
TikTok经常更新网页版DOM结构。如果脚本无法提取链接（显示0个链接），可能是选择器失效。
- **解决方法：** 联系我更新脚本，或临时回退到手动复制方式

### 4. 需要登录TikTok
TikTok网页版必须登录才能正常浏览短剧页面。未登录状态下页面结构可能不同，脚本可能无法正常工作。

## 🔄 如果Bookmarklet失效了怎么办？

Bookmarklet失效通常是因为TikTok更新了网页结构。有两个应对方案：

### 方案A：用浏览器控制台手动运行（临时应急）

1. 在TikTok短剧页面按 `F12` 打开开发者工具
2. 切换到 Console（控制台）标签
3. 打开 `tiktok-extract-bookmarklet.js`（可读版源码）
4. 复制全部代码粘贴到控制台，按回车运行
5. 如果报错，告诉我报错信息，我来修复

### 方案B：升级为油猴脚本（更稳健）

如果Bookmarklet经常失效，可以改用Tampermonkey油猴脚本：
- 油猴脚本会自动在TikTok页面上注入按钮
- 更容易维护和更新
- 需要安装Tampermonkey浏览器扩展
